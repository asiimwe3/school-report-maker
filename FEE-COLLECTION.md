# Fee Collection Guide

The admin console keeps **School fees**, **Boarding fees**, and **Bursary** as separate ledgers. A payment entered in one ledger never changes the balance in another.

## Before collecting

1. Create the academic year and select its current term.
2. Add classes and enrol students into the correct class for that year.
3. Open **Fee Collection** and choose a class.
4. Select the ledger you want to manage: School fees, Boarding fees, or Bursary.
5. Set the expected amount for that class and term. Repeat for every ledger that the class uses.

Old installations remain compatible: fee records created before this feature are treated as **School fees**.

## Recording a payment

1. Select the correct ledger first. Check the ledger name in the page heading before saving.
2. Select the student, enter the received amount, payment method, and receipt number where available.
3. Save the payment. The collection message confirms the amount, student, and ledger.
4. Use the balances table to check that only the selected ledger changed.

Use the receipt number for a bank slip, mobile-money transaction ID, or manual receipt-book number. This makes later verification much easier.

## Bursary policy

Use the **Bursary** ledger to track bursary funding promised or received for a student/class. It is intentionally not deducted from School fees or Boarding fees automatically, because each school has its own bursary policy. Record a matching School-fees or Boarding-fees payment only when the bursary funds have actually been applied to that obligation.

## Balances, reports, and defaulters

The balances table displays expected amount, paid amount, balance, and status for the selected class, term, and ledger. A learner can be cleared for School fees but still have a Boarding-fees balance; this is correct and visible.

The defaulter-list export is named with the ledger type, so lists cannot overwrite each other. Report cards print separate sections for each active fee category, with its own expected, paid, and balance figures.

## Good daily controls

- Reconcile cash, bank, and mobile-money totals against receipt numbers before closing the day.
- Record refunds or corrections using a documented local procedure; do not overwrite a receipt without preserving the audit trail.
- Export a backup before bulk changes and keep it somewhere separate from the main computer.
- Give finance staff access only to the screens and data they need.
