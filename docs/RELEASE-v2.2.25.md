# Release v2.2.25

## UI refresh

- Refined the admin console navigation rail with a clearer brand mark, grouped spacing, active-page treatment, and offline status.
- Added a persistent admin context bar showing the school, academic year, current term, and local-save status.
- Improved page titles, card surfaces, and dashboard readability without changing the underlying offline workflows.
- Refined the teacher home screen with school and term context, a direct mark-entry action, and a clearer daily snapshot.
- Grouped teacher tools by teaching, school operations, and data/account so common tasks are faster to find.
- Added a concise teaching-load summary to the classes screen.

## Compatibility

- Existing school data remains compatible.
- Teacher APK version `1.13.12` uses version code `26` and keeps the existing signing configuration for in-place updates.
