# Privacy Policy

1. **We store nothing about you.** The software is fully offline. Student names, marks, comments and reports live only on your school's computers, phones and USB drives.
2. **No accounts, no tracking, no analytics.** No sign-in, no advertising, no behaviour tracking. The app does not know who is using it.
3. **Update checks.** On startup the apps request a small version file from our public GitHub releases page. Only that request is made — no school data is ever sent.
4. **Crash reports.** If an app crashes, the technical error is saved to a file on your device (`crash-log.txt`). Nothing is sent automatically. The "Send crash report" button opens WhatsApp so **you** choose to share it with support.
5. **WhatsApp support.** When you contact support on WhatsApp, normal WhatsApp privacy applies to that conversation.
6. **Student data on staff phones.** The teacher app keeps marks in the phone's internal storage (survives offline use). The school is responsible for the devices it installs the app on.
7. **Deletion.** Uninstalling removes the app's files. Restoring a backup replaces the current database — keep your own extra copies.
